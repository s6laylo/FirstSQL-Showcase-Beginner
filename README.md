FirstSQL Showcase - Beginner

This is my first SQL project and is being used to document my progress while learning SQL.

The project is based around a fictional record company database containing bands, albums and songs. I'm working through a set of exercises that start with the fundamentals and gradually introduce more complex queries.

The database has three main tables:

- bands
- albums
- songs

These tables are connected through primary and foreign keys. A band can have multiple albums, and each album can have multiple songs.

What I'm Learning

I'm using this project to get more comfortable with SQL and relational databases, particularly:

Creating and modifying tables
Primary and foreign keys
SELECT queries
Filtering and sorting data
Joins
Aggregate functions
GROUP BY
INSERT, UPDATE and DELETE
Working with multiple related tables

I'm completing the exercises individually and saving my solutions as I go so that the repository shows my progress rather than just the finished result.
